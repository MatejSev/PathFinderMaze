# PathFinderMaze
Tento projekt simuluje sběr bludišťáků v bludišti pomocí robotů. Každý robot má za úkol vyzvednout bludišťáka a dopravit ho do určeného sběrného bodu. Každý robot může vézt najednou pouze jednoho bludišťáka. Roboti znají počáteční pozice bludišťáků a sběrného bodu, ale nemohou mezi sebou komunikovat, dostávají pouze pokyny.
